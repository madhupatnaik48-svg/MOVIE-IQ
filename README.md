# 🎬 MovieIQ — Predictive Analytics on Film Success

An end-to-end machine learning project that predicts whether a movie will be
**commercially successful** (`Revenue > Budget`) using its budget, popularity,
runtime, audience rating, and genre — wrapped in an interactive Streamlit dashboard.

> A movie is labeled **successful (1)** if `Revenue > Budget`, and **unsuccessful (0)**
> otherwise. This is a binary classification problem.

---

## 📌 Overview

| | |
|---|---|
| **Problem type** | Binary classification |
| **Target** | `success` = 1 if `revenue > budget`, else 0 |
| **Model** | Random Forest Classifier (scikit-learn) |
| **Features** | `budget`, `popularity`, `runtime`, `vote_average`, one-hot encoded `genre` |
| **Excluded** | `revenue` (leaks the target), `title` (no predictive signal) |
| **Dashboard** | Streamlit — genre/rating filters, live charts, statistical test results, and a prediction form |

**Why this matters:** greenlighting a film means committing a large budget before any
revenue is known. A model that estimates success probability from planning-stage
inputs helps studios, investors, and producers assess risk before production begins.

---

## 🗂 Dataset

`movies.csv` — 2,000 movies with:

- `budget` — production budget (USD)
- `revenue` — box-office revenue (USD)
- `popularity` — a popularity score
- `runtime` — runtime in minutes
- `vote_average` — average audience rating (0–10)
- `title` — movie title
- `genres` — stringified list of `{id, name}` genre dicts (TMDB-style)

Rows with `budget <= 0` or `revenue <= 0` are dropped during cleaning, since a zero
value signals missing financial data rather than a real $0 movie.

## ▶️ Run Locally

**1. Run the notebook first** (this generates the charts in `assets/` and the model
files in `models/`):
```bash
jupyter notebook MovieIQ_Project.ipynb
```
Kernel → Restart & Run All.

**2. Launch the dashboard:**
```bash
streamlit run MovieIQ.py
```
Then open the URL Streamlit prints — typically `http://localhost:8501`.

> The prediction section needs `models/random_forest.pkl`, `models/mlb_encoder.pkl`,
> and `models/feature_columns.pkl` to exist. If they're missing, the app shows a
> friendly warning instead of crashing — just run the notebook once first.

## 🖥 Dashboard Features

- **Sidebar filters** — genre and minimum vote-average, live-updating all charts/metrics
- **Dataset Summary** — filtered movie count, success rate, average budget/revenue
- **Interactive Charts** — budget vs revenue scatter, genre success-rate bar chart,
  vote-average boxplot, correlation heatmap
- **Statistical Test Results** — live t-test and chi-square test output with plain-English conclusions
- **Prediction Section** — enter budget, popularity, runtime, vote average, and genre
  to get a Success / Not Successful prediction with probability and confidence

---

## 🧠 Key Findings

- Budget and revenue are positively correlated (~0.76), but a large budget does not
  guarantee success — many high-budget films still fall below the revenue = budget line.
- Popularity differs significantly (p < 0.05) between successful and unsuccessful
  movies (independent t-test).
- Genre is **not** significantly associated with success in this dataset (chi-square
  p ≈ 0.99) — visual differences in per-genre success rate are consistent with random
  variation, not a real effect.
- None of the individual numeric features correlate with `success` above ~±0.05,
  which caps how strong any model built on this data alone can be.

## 🚀 Deploying to Streamlit Community Cloud

1. Push this repo to GitHub, **including** `movies.csv` and the three files in
   `models/` (train them locally first — Streamlit Cloud won't run the notebook for you).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. **New app** → select this repository/branch → set **Main file path** to `MovieIQ.py`.
4. Click **Deploy**. Dependencies install automatically from `requirements.txt`, and
   you'll get a public URL like `https://<your-app-name>.streamlit.app`.

**Checklist before deploying:**
- [ ] `models/random_forest.pkl`, `mlb_encoder.pkl`, `feature_columns.pkl` are committed to the repo
- [ ] `movies.csv` is committed to the repo
- [ ] All file paths in the code are relative (they are, by default)

## ⚠️ Limitations

MovieIQ's prediction is a decision-support signal, not a guarantee. The model has no
visibility into marketing spend, release-date competition, cast/director reputation,
or franchise effects — all of which materially affect real box-office outcomes.
